# Amplifier Agent engine

Owned execution policy, Amplifier integration, and private binding connections.
This distribution is an implementation dependency of the language bindings.

Install the [Python binding](https://github.com/microsoft/amplifier-agent/blob/v1/docs/install.md#python)
or [TypeScript binding](https://github.com/microsoft/amplifier-agent/blob/v1/docs/install.md#typescript)
to use Amplifier Agent. This package has no supported caller API or command-line interface.

See [the architecture guide](https://github.com/microsoft/amplifier-agent/blob/v1/docs/development/architecture.md).
