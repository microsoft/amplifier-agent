# Incident 2026-09-18: compaction storm on long sessions

Tracking id: INC-77410

## Summary

Sessions running past roughly 90k estimated tokens entered a compaction loop:
every request compacted, the request view never dropped below the target, and
the loop spent most of its time inside `_compact_ephemeral`.

## Timeline

- 09:12 UTC first report from the CLI team, a 4 hour refactoring session
- 09:40 UTC reproduced with `tests/test_compaction_storm_irreducible_floor.py`
- 11:05 UTC root cause confirmed: protected tool results were counted against
  the target but never eligible for truncation, so the ladder ran to level 8 on
  every request
- 13:30 UTC fix merged, irreducible floor now short-circuits the ladder

## Follow-ups

- Emit `context:compaction` with the strategy level reached so storms are
  visible in logs
- Document the floor in the README
